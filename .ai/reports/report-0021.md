## Shared state and `src0` versus `src`

Added `docs/LLAMA-PERF/tools/test_qsa_gdn_shared.cpp`, a bounded local C++ integration fixture using the public memory copy/decode APIs and the existing internal diagnostic bridge. It creates a four-token sequence 0 prefix, `seq_cp(0,1)`, advances sequence 1, and checks layer 1 R/S/P against an independently continued donor with the **same token**. The shared prefix and untouched donor remain byte-identical; the two same-token continuations are byte-identical and S changes from the prefix. A second copy and different tokens on seq1/seq0 produce distinct S, while the donor remains intact until its own continuation. These checks are enforced by the fixture, not inferred from metadata. The graph-disabled mixed-device run's nine checkpoints yield 27/27 identical layer-1 serializer/observer R/S/P rows (32,735,232 bytes); `--require-staged-source` passes.

For seq1 after each split, physical cell = 1, staged `src0=0`, stable `src=1`, serialized logical row = 1, with donor sequence 0 in cell 0. `seq_cp` shares the old tail; `find_slot` copies its source to the new empty cell, stages it in `src0`, normalizes `src` to the destination, and `s_copy` supplies the staged source to graph inputs. This is real cross-cell input dependency, **not** a nontrivial stable serialized-src test. Source review explains normalization in this path; it does not prove every possible lifecycle has no stable indirection. The test validates one layer and a compact schedule, not general multi-sequence or GPU-graph safety.

## Decision

The earlier measured sparse/dense logits and recurrent drift is unchanged. Do not promote or run full-model performance A/B. Next choose a separate, user-approved model-fidelity/task-quality rubric with dense controls, or investigate a sparse arithmetic variant closer to dense with headwise and logits regression; neither observer equality nor this test establishes a product tolerance. No 98K replay, Actions, GPU reset, or default/selector/overflow relaxation was performed.
