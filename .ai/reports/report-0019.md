The observer checks supported scalar types, contiguous element stride, bounds, sequence ownership and source/plane bounds; recurrent tensors are allocated as 2-D rows on their assigned layer devices. Source review confirms `state_write` selects `rs_idx * size + (cell.src >= 0 ? cell.src : cell_index)`, and `state_write_data` serializes R/P then S rows. The new runtime range check exercised all present 36 R, 36 S and one P tensor per checkpoint on the mixed-device model, including planes 0, 2 and 3. It verifies the selected byte range, layer, row size and type through the same tensor objects, but does not independently test backend transfers against a separate serialized byte stream. These are limits on observer validation, not proof of general mixed-sequence correctness.
